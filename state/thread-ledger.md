# THREAD LEDGER — every setup and its state

**What this is.** The live register of setups. A setup is any object, promise, question, or capability
introduced with enough weight that a reader will remember it. Weight is the operative word: a
mentioned chair is not a setup; a chair somebody refuses to sit in is.

**The three states** (see `references/craft.md` §6):

- **PAID** — discharged on the page.
- **BANKED** — explicitly acknowledged as still open, on the page. A craft act, not an evasion.
- **OPEN** — planted, unpaid, and not yet acknowledged as deliberately held. Legitimate while the
  book is running; it is the state that needs watching.

**ORPHANED is not a state you record. It is the failure this file exists to prevent:** planted with
weight, never referenced again by anything, and invisible to every per-chapter check because the
chapter that plants it is fine and the chapters that fail to pay it do not know it exists.

**Maintenance.** Update in post-flight, every chapter, alongside the other state files. `span-check.sh`
reads this file and reports OPEN threads untouched across a span. This supersedes the PENDING PAYOFFS
list in `story-bible.md` and the one-off map in `state/structural-diagnostic.md`; both are retained as
history, neither is maintained.

Format: `thread | planted | last watered | state | note`
