# chapters/

Drafted chapters land here, one file per chapter, named `ch-NN-slug.md`
(zero-padded), e.g. `ch-01-the-hill-is-sold.md`.

Each file opens with front matter:

```
---
chapter: 1
title: The Hill Is Sold
pov: Opus (third limited, past tense)
part: I — Spring
season_day: Spring, arrival
words: 2500
threads: [building, grief, undercurrent]
---
```

Then the prose. Do NOT repeat the title as an in-scene heading.
